ABOUT

A personal project, built in the open

Kaminari Seasonals Dashboard is a free, non-commercial personal project created and run by G T, who publishes under the name Kaminari Precision Trading. It is not a company or registered business.

Why it exists

It started as a research tool: one place to check seasonal tendencies against price behaviour, the macro calendar and an AI second opinion. It's also a live portfolio piece showing data engineering, front-end and AI integration work.

What it isn't

It isn't a broker, an adviser, a signal service or a paid product. It isn't licensed by NBFIRA or any regulator. It takes no payments and holds no accounts. See the Risk Disclosure.

How it's built

A static HTML, CSS and JavaScript site hosted on Netlify, with a Python data pipeline over MetaTrader 5 history and optional AI analysis. The code is on GitHub.
